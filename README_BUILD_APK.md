# Quick Follow Android APK Build Guide

## Option 1: Free Cloud APK Build (No PC Needed — Using GitHub Actions)
1. Create a new repository on github.com.
2. Upload all files inside this ZIP to the repository.
3. Open the **Actions** tab on GitHub -> click **Build Quick Follow APK** -> **Run workflow**.
4. In ~2 minutes, download **QuickFollow-APK** containing `app-debug.apk` directly to your Android phone!

## Option 2: Android Studio (PC)
1. Open this folder in Android Studio.
2. Run **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
3. Install `app/build/outputs/apk/debug/app-debug.apk` on your Android device.
